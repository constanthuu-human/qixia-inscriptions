QIXIA WEBSITE UPDATE — UPLOAD THESE FILES

1. Download this ZIP and double-click it to unzip it.

2. Open the existing repository:
   https://github.com/constanthuu-human/qixia-inscriptions

3. Click Add file → Upload files.

4. From the unzipped folder, upload:
   - the six .html files;
   - the assets folder, including its images folder.

   These files update the six new sections. Keep the existing temple-map.html,
   Qixia stone files, maps, and other repository files.

5. At the bottom, choose Commit directly to the main branch.

6. Click Commit changes.

7. Open Settings → Pages and confirm:
   Source: Deploy from a branch
   Branch: main
   Folder: /(root)

8. Wait for the Pages deployment to show a green checkmark.

The six pages are:
monk-day.html
monks.html
buddhist-objects.html
buddhist-images.html
buddhist-legends.html
buddhist-branches.html
