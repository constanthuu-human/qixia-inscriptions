# New image upload folder

This folder is reserved for the new pages in the Jiankang Historical Network.

The first build preserves the existing Qixia and temple photographs already in the repository, so no historical image was copied, renamed, or replaced. When new photographs or licensed images are ready, upload them here with simple lowercase filenames such as:

- monk-day.jpg
- monk-portrait-01.jpg
- buddhist-object-01.jpg
- buddhist-image-01.jpg
- buddhist-legend-01.jpg

Then change the relevant `src="./..."` paths in the page that uses each image.
